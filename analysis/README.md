# 설계 근거 분석 스크립트

라우팅 정책 결정에 사용한 탐색·검증 코드입니다. 제출 이미지에는 포함되지
않으며, 보고서에 기재한 수치의 산출 과정을 확인하는 용도입니다.

실행에는 pandas, scikit-learn, matplotlib이 필요합니다(제출물 미포함).

## 문제 경계 파악

| 파일 | 내용 |
| --- | --- |
| `analyze.py` | 하한(전 문항 경량 모델)과 오라클 상한 산출, 문항별 승격 가성비 계산 |
| `profile.py` | 프롬프트 표면 특징으로 5개 그룹 분류, 그룹별 모델 성능 비교 |
| `eff.py` | 그룹별 승격 효율과 기준 비용 점유율 산출 |
| `mkdev.py` | Train/Dev를 분석용 CSV로 변환 |

## 예측 가능성 검증

| 파일 | 내용 |
| --- | --- |
| `diag.py` | Fast 등급 승격 결과를 사후 분석 (실제 이득 vs 최적 배분) |
| `gain.py` | Ridge의 선형성으로 "점수 차 예측"과 "이득 직접 예측"이 동일함을 확인 |
| `models.py` | Ridge·로지스틱·그래디언트 부스팅 5종의 이득 예측력 비교 |
| `filter.py` | 예측 점수로 승격 후보를 선별하는 전략 검증 (역효과 확인) |
| `think.py` | 추론 모델 승격 이득의 예측 가능성 측정 (상관 0.358) |
| `ml.py` | TF-IDF + Ridge 기반 문항별 점수·토큰 예측 실험 |

## 비용 추정과 정책 설계

| 파일 | 내용 |
| --- | --- |
| `cost_est.py` | 출력 토큰 분포 분석, 그룹 평균 기반 비용 추정 오차 측정 |
| `calibrate.py` | 모델별 실제/예측 총비용 배율 산출 및 log-cost head 보정 |
| `policy.py`, `policy2.py` | 예산 제약 하 배분 정책 시뮬레이션 |
| `sim.py`, `think2.py` | 그룹 규칙 기반 배분 시뮬레이션 |
| `shrink.sh`, `sweep.sh`, `tune.sh` | 점수 head 스케일과 안전계수 탐색 |

## 교차검증 (안전계수 결정 근거)

| 파일 | 내용 |
| --- | --- |
| `cv.sh` | 공개 자료 2,640문항을 5폴드로 분할 |
| `cvrun.sh` | 폴드별 학습 (각 2,112문항) |
| `cveval.sh` | 홀드아웃 528문항 평가, 비용 보정 계수는 폴드 학습셋에서만 산출 |
| `final.sh` | 통합 학습 계수의 등급별 안전계수 스윕 |

교차검증 결과는 저장소 루트 [REPRODUCE.md](../REPRODUCE.md)에 정리했습니다.
